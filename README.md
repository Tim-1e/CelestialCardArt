# 天体卡面 · Celestial Card Art

《杀戮尖塔 2》天体主题卡牌与遗物美术包。当前版本 **v1.1.1**，与 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3803362518) 的已发布内容一致。

[下载完整模组包](https://github.com/Tim-1e/CelestialCardArt/releases/latest) · [完整中英文介绍](CelestialCardArt.md)

## 本地安装

1. 在 [Releases](https://github.com/Tim-1e/CelestialCardArt/releases/latest) 下载 **CelestialCardArt-v1.1.1.zip**。
2. 退出游戏，将 ZIP 内的 `CelestialCardArt` 文件夹放进游戏安装目录的 `mods` 文件夹。
3. 安装并启用 [RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295) 0.5.20 或以上，重启游戏并启用天体卡面。

若已订阅本模组的工坊版，请只保留一种安装来源，避免重复加载。推荐搭配 [Skin Changer](https://steamcommunity.com/sharedfiles/filedetails/?id=3787302680) 管理卡面。

首次默认使用本包先古全幅、仅升级后播放（贪婪除外）。在「模组设置 → 天体卡面 → 卡面选择与预览」切换普通／先古、A/B 图稿或其他来源；动态设置也在同页，已有选择会保留。
